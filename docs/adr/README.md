# 아키텍처 결정 기록

아키텍처에 영향을 주는 결정은 이 디렉터리에 ADR로 기록한다.

## 형식

```text
# ADR-NNNN: 제목

## 상태
제안됨 | 승인됨 | 폐기됨 | 대체됨

## 맥락
왜 결정이 필요한가?

## 결정
무엇을 선택했는가?

## 결과
장점, 비용 및 후속 작업은 무엇인가?

## 대안
무엇을 검토했고 왜 선택하지 않았는가?
```
