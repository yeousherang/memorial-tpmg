# ADR-0001: 내부 모델로 TPMG 채택

## 상태

승인됨

## 맥락

단순 트리는 노드의 다중 원인, 서로 다른 경로의 합류, 기억의 재해석, 현재에 재활성화되는 과거 영향 및 반사실 세계선을 충분히 표현하지 못한다.

## 결정

내부 모델로 Temporal Probabilistic Multilayer Graph를 사용한다. 선택 트리는 내부 그래프에서 생성하는 뷰로 취급한다.

## 결과

- 여러 레이어와 관계를 명시적으로 표현할 수 있다.
- 시간, 확률 및 세계선이 모든 주요 API에 포함된다.
- 저장 및 질의 구현이 단순 트리보다 복잡해진다.
- 시각화는 목적에 맞는 투영 규칙을 필요로 한다.

## 대안

- 단순 트리: 구현은 쉽지만 재결합과 다중 영향을 표현하지 못한다.
- 일반 property graph: 유연하지만 도메인 계약과 타입 안전성이 약하다.
- 순수 이벤트 로그: 재생은 좋지만 관계 질의와 다층 분석이 어렵다.
