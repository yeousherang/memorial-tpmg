# Security Policy

## Supported Versions

Memorial TPMG is currently pre-alpha and has no supported production release. Security fixes are applied to the latest development branch only. Do not use the project to store real sensitive, clinical, or identifying personal data.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in a public issue. Email `yeousherang@proton.me` with:

- a description of the issue and its potential impact;
- affected files, versions, or commits;
- reproduction steps or a minimal proof of concept;
- any suggested mitigation, if available.

Reports will be acknowledged as soon as practical. Details should remain private until a fix or coordinated disclosure plan is available. Good-faith research that avoids privacy violations, data destruction, and service disruption is welcome.
